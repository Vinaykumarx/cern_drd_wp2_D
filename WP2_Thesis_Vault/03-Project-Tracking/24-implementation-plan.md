# VLM-Assisted Layout-Aware RAG & [CTO Roadmap] Agent Zero Intelligence Upgrade

As CTO, I am implementing a three-phase upgrade to the Agent Zero orchestrator. We will move from "Generic RAG" to a "Physics-Aware Agentic Swarm" that autonomously recommends sources and allows for deep-link navigation into scientific documents.

The goal of this architectural change is to solve the "nonsense chunks" issue. We will deprecate the blind text extraction (`PyMuPDF`) and table extraction (`pdfplumber`) steps, replacing them with a VLM (Vision-Language Model) pipeline that "reads" PDF pages as images, understands semantic layouts (multi-column text, tables), and outputs clean Markdown for intelligent chunking.

## Proposed Architecture Change

Currently, `extraction/extract_with_docid.py` runs steps sequentially. 
We will introduce `extract_vlm_layout.py` to replace `[1/5] Extracting text` and `[2/5] Extracting tables`. 

**The new flow:**
1. **PDF to Image**: We rasterize each page to a high-res image.
2. **VLM Transcription**: We pass the image to a Vision-Language Model with a prompt: `"Extract all text, headers, and tables from this page. Keep the reading order intact and format tables as Markdown. Ignore footers."`
3. **Structured Storage**: We save the output as `pages_text.json`, but instead of garbled text, it contains cleanly formatted Markdown.
4. **Header-Aware Chunking**: We update `core/rag_pipeline.py` to split chunks based on Markdown headers (`#`, `##`) rather than arbitrary character limits.
